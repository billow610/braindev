# 音频文件存放目录

请将课时对应的 mp3 音频文件放在此目录下，文件名需与 `src/data/units.js` 中配置的 `audioUrl` 对应。

## 文件命名规则

按课时 ID 命名，例如：
- `u1-l1.mp3` - 第一单元第一课
- `u1-l2.mp3` - 第一单元第二课
- `u2-l1.mp3` - 第二单元第一课
- ...

| u1-l2 | u1-l2.mp3 | 1.2 大脑的主要分区 |
| u1-l3 | u1-l3.mp3 | 1.3 神经元与神经递质 |

| u2-l3 | u2-l3.mp3 | 2.3 什么是神经可塑性？ |
| ... | ... | ... |

## 注意

- 如果没有放入对应的 mp3 文件，播放器会显示"音频加载失败"的提示
- 建议音频格式为 mp3，码率 128kbps 或以上
